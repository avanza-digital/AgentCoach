# AgentCoach

Agente coach comercial para los analistas de ventas de Avanza Digital: responde dudas de gestión comercial (objeciones, cierre, preguntas técnicas, comunicación) a partir de las capacitaciones y libros validados por el CEO, con cita a la fuente.

Arquitectura: RAG sobre Postgres + pgvector, búsqueda híbrida (vector + texto), generación con Claude.
